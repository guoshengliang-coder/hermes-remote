## 1. 这个页面是什么

会话列表页左上角的**头像按钮**点开的一张侧滑抽屉（Material 3 `ModalNavigationDrawer` + `ModalDrawerSheet`），
项目内叫「卡片页」。它是 App 的"个人 / 全局入口"聚合页：当前身份、本周用量、远程设备状态、几条全局设置
和功能入口。它**不是**设置页 —— 设置页（齿轮）是它的子页面之一。

- 只从会话列表页打开（头像按钮或从列表左缘右滑）；聊天页内不允许侧滑拉出。
- 抽屉宽 86% 屏宽、上限 360dp，右缘圆角 22dp，遮罩 32%。
- 内容自上而下：字标 + 齿轮 → 身份卡 → 统计卡 → 快捷行列表。整页可竖向滚动。

## 3. 逐元素说明（现状）

### 3.1 顶部：字标 + 齿轮
- 左：`Hermes GO` 字标，26sp Bold，占满剩余宽度。
- 右：44dp 圆形齿轮按钮 → 设置页。浅色用 6dp 阴影浮起、底色 = surface；深色阴影不可见，改为一阶提亮填充、无阴影。
- 齿轮必须**带齿圈**（历史上"太阳式"齿轮被误读为亮度调节，已废弃）。

### 3.2 身份卡（只显示当前身份）
- 圆角 20dp 淡卡；内容：48dp 头像 + 大字 + 副行 + 20dp 细箭头。整卡可点 → 身份选择页（`05` 截图）。
- 大字 20sp：有自定义显示名时 = 显示名；否则 = profile 名（如 `default`）。
- 副行 15sp 次要色：有自定义显示名时 = profile 名；否则 = 「当前身份 / Active profile」。
- 头像渲染优先级：照片 → 自定义色 → 按 profile 名哈希的自动色。字母头像有实心（填充 + 白字）与空心（描边 + 彩字）两种样式；
  字母取显示名首字，字号 ≈ 0.47 × 圆径 SemiBold。
- 这里**只**有 Hermes 身份（profile），Hermes GO 账号（邮箱登录）不在卡片页露出，只在设置页。这是明确决策，不能合并。

### 3.3 统计卡（一张卡、两格、中间贯穿竖发丝线）
- 圆角 20dp 淡卡，两格各 `weight(1f)`，格内边距水平 14dp、竖 18dp。
- **两格都是入口**：左「本周用量」→ 用量页；右「远程设备」→ 远程设备页。各带 16dp 细箭头（比行尾箭头小一档），涟漪覆盖整半格。
  规则：要么给箭头，要么别绑点击，不允许隐形可点区。
- 每格三行：标题 15sp 次要色 / 数值 23sp Bold（字距 -0.3）/ 副行 15sp。
- 左格：数值 = 本周 token 总量（紧凑格式，如 `14.7M`；无数据 `—`）；副行 = `N 次会话`。
  曾经显示美元估算，2026-09-03 决策改为会话数（费用只是下界，会被误读为账单）。
- 右格：数值 = 设备名（如 `mac-mini`；未连接时 `未连接 / Offline`）；副行 = `已连接 · 29 ms`（延迟 <1000ms 显示 `N ms`，否则 `X.X s`），
  连接器离线时副行 = `连接器离线 / Connector offline`，**用错误色**。
- 文本适配（§3.3 三级策略）：数值与副行先逐级缩字（数值下限 13sp、副行下限 11sp），到下限仍溢出则**保持下限折两行**，
  两行仍溢出才省略号。两格的数值字号、副行字号**锁步**（任一格缩，两格一起缩）。两格**顶部对齐**，不得整格垂直居中
  （HG-14：右格折两行时左格整体下沉）。
- 远程设备格是绑定 Mac 的**唯一入口**（手机端不再新增"连接与设备"入口）。

### 3.4 快捷行（图标 + 标题 [+ 徽标/红点] [+ 右值] + 细箭头）
行高：上下各 18dp 内边距；图标 22dp；标题 17sp；右值 15sp 次要色（最大宽 160dp，缩字下限 12sp）；行尾细箭头 20dp；行间发丝线分隔。

| 行 | 图标 | 右值 | 点击 | 附加状态 |
|---|---|---|---|---|
| 定时任务 / Scheduled jobs | 时钟 | 无 | → 定时任务列表页 | 有待处理告警时标题后出现**中性色数字徽标**（surfaceVariant 底，不用警示色） |
| 主题 / Theme | 月亮 | 随系统 / 浅色 / 深色 | 弹底部三选一（`04` 截图），与设置→外观共用同一存储 | — |
| 模型 / Model | 立方体 | 默认模型名（无则 `—`） | → 模型页 | — |
| 检查更新 / App updates | 下载盒 | `v0.1.116`；有新版时 `新版本 0.1.117 / New 0.1.117` | → 检查更新页 | 有新版时标题后 7dp **错误色红点** |
| 反馈与建议 / Feedback | 对话气泡（空心） | 无 | 直接拉起 MissionGo 反馈编辑器（独立 Activity，不是路由） | **构建里没配 MissionGo endpoint/token 时整行连同分隔线都不存在**（截图机上就是这种情况，所以只有四行） |

入口行范式：纯展示无箭头，可点必有箭头。

### 3.5 主题底部弹层
- `ModalBottomSheet`，标题「主题」左对齐（titleMedium，与列表项共用 24dp 左基线），三个 `ListItem` + RadioButton。
- 全局硬规则：底部弹层禁止半展开中间态，内容多高弹多高。

## 4. 视觉与排版约束（重新设计时必须继承）

### 4.1 色彩（暖调换肤 2026-09-10 之后）
| 角色 | 浅色 | 深色 |
|---|---|---|
| 抽屉容器 `surface` | `#FAF9F5` 暖纸 | `#0F1217` |
| 淡卡 `tileColor()` | `#FFFFFF`（纯白 = 浮起层）+ 1dp 阴影 | `lerp(surface, White, 0.06)`，无阴影 |
| 发丝线 `hairlineColor()` | `#EFEEEA` | `lerp(surface, White, 0.14)` |
| 正文 `onSurface` | `#1B1C1A` | — |
| 次要文字 `onSurfaceVariant` | `#494641` | `#A8A49C` |
| 品牌主色 `primary`（chrome 一律品牌色） | `#004AC6` | 未定案 |
| 错误色 `error`（离线副行、更新红点） | `#BA1A1A` | — |

- **淡卡语言**：卡片轮廓靠微差 + 微影，不靠重填充；浅色"卡比底亮"，深色"卡比底微亮一阶"，深浅两模式必须同一语言。
- 深浅判定看**实际生效的主题**（应用内可选），不是系统设置。
- ~~无障碍下限硬于设计稿~~ —— 四条下限已于 2026-09-11 废除，冲突时一律照稿（`DESIGN.md` §7 第 8 条）。

### 4.2 字号（卡片页锁定尺度）
整页 `fontScale = min(系统, 1.0)`，系统大字号不会放大卡片页（用户明确要求；此锁**不得**扩散到聊天等阅读界面）。

| 元素 | 值 |
|---|---|
| 字标 | 26sp Bold |
| 身份名 | 20sp |
| 统计标签 / 副行 | 15sp |
| 统计数值 | 23sp Bold（缩字下限 13） |
| 快捷行文字 | 17sp |
| 快捷行右值 | 15sp（缩字下限 12） |

字体 = 系统默认（`FontFamily.Default`），没有品牌字体。

### 4.3 图标
- 统一 1.7dp 描边、圆头圆角、24×24 手绘矢量；**不混用** Material 填充式 / outlined 图标（弹出层例外，沿用 Material Rounded）。
- 卡片页私有：齿轮、时钟、月亮、立方体、下载盒、细箭头；公共：对话气泡（反馈）。
- 尺寸：行内 / 齿轮钮内 22dp；行尾箭头 20dp；统计卡箭头 16dp。

## 5. 截图未覆盖、设计必须考虑的状态

1. 身份卡有**自定义显示名**：大字 = 显示名，副行 = profile 名。
2. 头像为**照片**、或**空心字母**样式。
3. 左格无数据（`—`）；数值很长（如 `1.23B`）与设备名很长（如 `guoshengliang-macbook-pro`）同时出现 → 触发锁步缩字 / 折两行。
4. 右格**连接器离线**：数值 `未连接`，副行 `连接器离线` 错误色。
5. 定时任务行带**数字徽标**；检查更新行带**红点** + 右值 `新版本 x.y.z`。
6. 存在**反馈与建议**行（五行）与不存在（四行）两种布局。
7. 英文界面（App 内可切语言）：`Hermes GO / Active profile / This week / N sessions / Remote device / Connected · 29 ms /
   Connector offline / Scheduled jobs / Theme (System · Light · Dark) / Model / App updates (New x.y.z) / Feedback / Settings`。
8. 深色 + 系统浅色的组合（历史 bug 组合，必须验）。
9. 抽屉打开时遮罩后面是会话列表；预测性返回手势 / 返回键先关抽屉、绝不退出 App；
   从卡片页进入的子页面按返回时**重新打开卡片页**（reopen 机制）。

## 6. 交互契约（重新设计不能破坏）
- 头像按钮打开；从列表左缘右滑也可打开；聊天页内不可滑出。
- 返回键 / 预测性返回：先关抽屉。子页面返回 → 卡片页恢复打开。
- 快捷行点击后抽屉关闭、推入目标页；主题行例外（弹层，抽屉不关）；反馈行例外（拉起外部 Activity）。
- 主题选择即时生效并持久化（与设置→外观同一存储）。

## 7. 已知的可改良点（供设计参考，非结论）
- 整页下半段大面积留白（四到五行之后无内容），信息密度低。
- 「模型」右值在 mock 下为 `—`，真实环境是较长的模型 ID（如 `claude-opus-5`），右值区 160dp 上限容易触发缩字。
- 统计卡右格副行「已连接 · 231 ms」在部分设备名下会折两行（合法但不美观）。
- 齿轮钮浅色用 6dp 阴影，是页面里唯一的"重阴影"，与淡卡的 1dp 阴影不是同一语言。
- 身份卡与统计卡之间 16dp、统计卡与快捷行之间 10dp，节奏不完全一致。
- 反馈行"有时存在有时不存在"，列表长度不稳定。
