# 粘进 Stitch 生成框的提示词（卡片页 · 浅色）

> 用法：在 Stitch 项目「Hermes GO」里先把本目录的 5 张 PNG 与 `README.md` 拖进画布，再把下面这段整段粘进生成框。
> MCP 通道发不进图片，`generate_screen_from_text` 也不产出画面（2026-09-11 两次实测），所以只能手动。
> 生成后按 `基线-卡片页/默认/浅色` 的惯例打标签；暗夜版从浅色版派生（只改颜色，几何不动）。

---

候选-卡片页/默认/浅色 —— Hermes GO Android 客户端「卡片页」重新设计（浅色），一张 390×844 手机屏。

页面：会话列表左上角头像点开的侧滑抽屉（Material 3 modal drawer）。抽屉从左打开、宽 86%（上限 360px）、右缘上下圆角 22px；右侧露出被 32% 黑遮罩压暗的会话列表（示意：顶栏「会话」+ 几行会话）。抽屉底色 = 暖纸 #FAF9F5，内容左右内边距 24px，顶部避开状态栏。参考图：02-card-light.png 是现状，01 是入口。

抽屉内容自上而下（全部保留，顺序不变）：
1. 顶部：左「Hermes GO」字标 26px Bold；右 44px 圆形齿轮按钮（描边式、带齿圈，22px）。不要重阴影，用一阶容器色 #EFEEEA 填充即可。
2. 身份卡：圆角 20px 纯白 #FFFFFF 淡卡 + 1px 微影。48px 圆形字母头像（实心 #8B2252 + 白色「D」）→ 大字「default」20px → 副行「当前身份」15px #494641 → 行尾 20px 细箭头。只显示 Hermes 身份，不显示邮箱账号。
3. 统计卡：圆角 20px 纯白淡卡，左右两格各半，中间贯穿竖发丝线 #EFEEEA。每格三行：标题 15px #494641 / 数值 23px Bold / 副行 15px。左：「本周用量」「14.7M」「77 次会话」；右：「远程设备」「mac-mini」「已连接 · 231 ms」。两格都可点，各带 16px 细箭头紧跟数值行右侧；格内边距水平 14px、竖 18px；两格顶部对齐，不要垂直居中。
4. 快捷行（上下各 18px 内边距，图标 22px 描边式，标题 17px，右值 15px #494641，行尾 20px 细箭头，行间 1px 发丝线 #EFEEEA）：
   - 时钟「定时任务」，标题后中性数字徽标「2」（#E3E2DF 底胶囊，不用警示色）
   - 月亮「主题」，右值「随系统」
   - 立方体「模型」，右值「claude-opus-5」（右值区要容得下长模型名）
   - 下载盒「检查更新」，标题后 7px 红点 #BA1A1A，右值「新版本 0.1.117」
   - 空心对话气泡「反馈与建议」，无右值（有的构建没有这一行，少一行也要好看）

视觉规则：暖纸底、暖中性族、不出现冷灰；卡片轮廓靠微差微影不靠粗描边；纯白只用于淡卡；品牌蓝 #004AC6 只用于 chrome；红色只用于更新红点和离线副行；图标 1.7px 描边、圆头，不用 Material 填充字形；系统无衬线字体（Roboto Flex 近似），不用等宽；文字 ≥12px、触控 ≥48px、正文对比 ≥4.5:1；可点必有细箭头，纯展示无箭头。

改良目标：列表之后的大面积留白要有更好的纵向节奏；身份卡/统计卡/列表之间间距一致；齿轮钮不再是页面唯一的重阴影；副行折行要有余量。只出这一张浅色版，全部中文文案。
