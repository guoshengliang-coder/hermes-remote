规格

光晕 = 气泡形状向外扩 8dp 的同形描边（`drawBehind` 画圆角矩形，`primary` 浅色 / `Blue80` 深色），alpha 从 0.28 线性到 0 共 1200ms，标准缓动；不改气泡底色，不加边框；搜索命中仍用原描边样式，两者不共用。若同一条再次被跳转，重新从 0.28 开始。
