## 实现前测试影响审查

- Controller：九档倍率、实际反馈、保持音调、暂停/结束/关闭取消临时倍率，拒绝倍率的 HR-FILE-018 双语错误。
- Compose：单击、长按释放/取消/多指、暂停不触发，控件不冲突；速度菜单、长按偏好、缓存副行；双主题与 1.3 字号截图。
- 缓冲：按真实播放时长限制高倍速最大缓冲，24MiB 压缩采样目标；原有启动、再缓冲判断仍由 Media3 按速率换算。
- 缓存：只统计同代完整校验片段，优先当前位置，重开补缺；有限预算、低空间、清理代次和停止后不回填。
- 仲裁：播放读/seek 抢占预缓存，明确下载等待播放但抢占预缓存，取消全部释放；最多四路同引用。
- 生命周期：暂停继续磁盘缓存；后台/离页/关闭取消；旋转保持常速但结束长按；返回不自动播放。
- 旧设备测试里“暂停停止所有网络”的断言必须移除，替换成暂停缓存继续、关闭与后台停止。

## 实现边界

Android 原画播放使用 Media3 1.11.1；本轮没有更改 Gateway、Connector、Desktop 或 Web 的协议/流量上限。
HR-FILE-018 与 HR-CACHE-003 只在 Android 本地状态使用，其他消费者不需要适配。
磁盘 filler 使用一条可抢占的空闲请求，不额外扩大协商并发；缓存命中不抢网络，真实播放 miss 先取消并排空 filler。
低空间恢复可重新准入；手动清理在本次观看持有旧 epoch，不因重试/旋转/前后台切换重新填满。
预缓存读取和覆盖检查不挤占实际播放片段的热保护集合；清理回归曾确认后台校验错误保留 16MiB，修复后只保留实际使用片段。
预缓存记录本次已尝试位置；容量已满或落盘未保留即停止，不能靠反复淘汰当前视频制造虚假的缓存进度。
首帧/seek 仍为已验证的小范围交付，没有实现未经测量的半片流式交付或 Mac 转码。
