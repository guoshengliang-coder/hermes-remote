# HG-243 · Android 视频批注

用户在本次派单会话批准：时间点与区间批注自动保存到本机，同一视频版本重开恢复，
同路径新版本分开记录；Markdown 加入原会话待发附件，由用户检查后发送。

## 交互与范围

2026-10-29 用户使用 0.1.186 后批准改为连续打点流程：进入「批注」只展开工具，不创建时间、不暂停。
竖屏上方视频下方紧凑工具，横屏左右分区；媒体黑底白控件，工具和评论采用生效主题。
三个固定动作「单点批注／起始点／终止点」，普通字号同排，大字号重新排列，触控至少 48dp。

单点捕获点击瞬间的已确认位置，暂停并拉起意见输入。起点捕获后可继续播放/拖动；重设起点和取消选段
明确可达。终点需已有起点且晚于起点，确认后暂停并评论；时间是只读引用，无手填时间表单。
拖动中和新画面定位未确认时禁打点。暂停 seek 为渲染目标帧短暂 prepare，渲染后 stop/release 播放优先权；
不会把播放器停留的旧帧当作新点。时间保留毫秒，不宣称逐帧精度。

评论可重新打点/选段并保留文字。「保存并继续」等待真实落盘成功后才收起评论、清临时选区、继续播放；
视频末尾不重播。已有批注改字后回列表，不自动播放。失败保持评论可重试，后台/离页后不能因迟到写成功而播放。
「稍后填写」和系统返回保留草稿；重开先显示工具，旧草稿通过独立入口恢复。新增打点先保留旧草稿，
未完成选段也可恢复，不强迫填时间。新建草稿与已存批注合计最多 500 条，每条意见最多 8,000 字符。
返回先收键盘、再保留编辑回工具，再退出批注/横屏/播放器；旋转只重排，后台回来由用户手动播放。

列表按时间排序，点击时间跳转后暂停，编辑和确认删除入口保留。列表底部提供导出，未提交草稿不计入正式反馈。

本机私有 `filesDir/video-feedback/` 保存批注和未提交的编辑草稿，不属于预览缓存，
清理视频缓存不删除批注。文档采用版本化 JSON，文件名对作用域、来源和视频版本做
长度编码再 SHA-256。读取失败禁止空白覆盖，写入经临时文件 fsync 后原子替换。
单个编辑会话串行合并写入最新快照，关闭播放器不取消已经发起的持久化。

作用域含 Gateway/账号、Mac、身份、会话；远程视频采用已验证的文件代际标识，
完整下载使用对应下载记录的同一代际。只有本地文件可用时使用该文件的本地版本标识。
不同代际不会自动迁移时间点，也不会把旧批注套到被覆盖的新视频上。

列表中可导出已保存批注；未提交草稿不混入正式反馈。导出包含来源引用、
视频名称、会话、视频时长和按时间排序的反馈正文。区间包含两端时间，正文保留换行和
Markdown。保存走系统文档创建器，用户自行选择位置；加入原会话只创建待发附件，
不调用发送，不替换已有草稿和附件。返回前重新检查作用域与附件容量。

## 失败与验证

错误在 `ERROR_HANDLING.md` 注册为 HR-ANNOT-001/002/003/004，分别对应本地存储、
导出/附件准备、输入校验和原会话附件已满。诊断只含阶段与异常类，不含批注、文件路径或账号信息。
Android 以外组件不消费这些本地错误，不变更协议、服务端接口或上游 Hermes。

自动化覆盖时间解析与边界、区间校验、顺序/格式、版本隔离、编辑草稿恢复、增删改、
最新写入胜出、读写失败恢复及诊断脱敏；L1 覆盖双主题、1.3× 字体和横屏。
真机的媒体画面定位、软键盘、系统文档保存以及原会话实际发送需按 ANDROID_SMOKE.md
验证。本次为源码改动，不分配或发布 APK。
